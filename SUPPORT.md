# Getting help

Wellface is maintained on a best-effort basis by one person. There is no response-time commitment.

## Questions about using or building Wellface

- Read the [`README`](README.md), [`docs/build.md`](docs/build.md), the [glossary](GLOSSARY.md) and the other docs in [`docs/`](docs/) first.
- Search the [existing issues](https://github.com/fugo101/wellface/issues?q=is%3Aissue), open and closed.
- If you do not find an answer, use the Question form under [New issue](https://github.com/fugo101/wellface/issues/new/choose). GitHub Discussions are not enabled.

## Bugs and feature requests

Use the issue forms under [New issue](https://github.com/fugo101/wellface/issues/new/choose). Read [`CONTRIBUTING.md`](CONTRIBUTING.md) before sending a pull request.

## Other watches

Only the Garmin Forerunner 265 is maintained. To run Wellface on another watch, read [Device support](CONTRIBUTING.md#device-support) and open an issue with the "Device port" form. Please do not ask for a port to a watch you do not own.

## Garmin, your watch and the Connect IQ tools

Problems with the Connect IQ SDK, the SDK Manager, the simulator, the Garmin Connect app or the watch itself belong to Garmin, not to this project; see the [Connect IQ developer forum](https://forums.garmin.com/developer/connect-iq/). If a script here fails because of one of them, an issue is still welcome, as long as it says which step failed and what the script printed.

## Security and conduct

- Security problems: do not use a public issue. Follow [`SECURITY.md`](SECURITY.md).
- Conduct problems: follow [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

## Privacy

Issues are public. Do not paste your developer key, Garmin account details, machine paths that contain your name, or health data from your watch into an issue, pull request or comment. Use made-up values.
